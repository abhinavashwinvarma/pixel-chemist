# Pixel Chemist
A chemistry-themed educational clicker game based on qualitative salt analysis.

# About
This was my first attempt at game development, and my submission to Brackey's Game Jam 2025.1. It ranked #1198, while my pixel art landed a #399 in the visuals category. The gameplay isn't the best, but it was an interesting project that taught one a lot of principles of gamedev.

# Built with
- Godot & GDScript
- LibreSprite
- BeepBox
